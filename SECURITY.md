# Security

The kit runs on developers' machines and in CI: it builds plugin bundles, runs shell scripts and installs dependencies. A problem here can reach every plugin that uses it.

## Reporting

Please report security problems privately through [GitHub security advisories](https://github.com/Dimagious/obsidian-plugin-dev-kit/security/advisories/new), not in a public issue. Include what is affected, how to reproduce it, and the kit version or commit.

Fixes go into a new release; tags are never moved.

## Supported versions

Only the latest release gets fixes.
